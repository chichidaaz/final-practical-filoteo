# Project Title

Charlize Filoteo Portfolio

# Overview

This is a personal portfolio website that shows my background, selected works, skills, and contact information. It is made as a midterm practical project.

# Features

- Mobile navigation menu toggle
- Light and dark theme switch
- Dynamically displayed portfolio works
- Contact form with validation and success message
- Saved theme settings using localStorage

# Technologies

- HTML
- CSS
- JavaScript

# Setup

1. Download or clone the project folder.
2. Open `index.html` in a web browser.
3. Make sure the `css.css`, `js/script.js`, and `assets` folder stay in the same project location.
